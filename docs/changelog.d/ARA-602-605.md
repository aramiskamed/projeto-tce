# Changelog — CranioMold 3D v2.0 (`ARA-602`, `ARA-603`, `ARA-604`, `ARA-605`)

- **SPEC:** `docs/specs/projeto-tce-craniomold/SPEC.md` (Tier `mvp`, revisada por auditoria adversária isolada)
- **Scaffold & Deploy (`ARA-602`):** Migração do esboço monolítico para **Vite 6 + React 19 + TypeScript 5 + Tailwind CSS v4 + Three.js r174 + Chart.js 4**, configuração `vercel.json` com CSP estrita e headers de segurança, GitHub Pages fallback (`VITE_BASE_PATH`) e `./scripts/quality_gate.sh`.
- **Motor CAD/CAM 3D Manifold (`ARA-603`):**
  - Grade em frame tangente ortonormal local `(tx, ty, defectDir)` eliminando singularidades polares.
  - 4 pinos Poka-Yoke no molde inferior + 4 cavidades fêmeas no molde superior paralelos a `defectDir` com folga radial exata `clearanceMm`.
  - Canaleta periférica de rebarba + 4 canais radiais de escape de PMMA + chanfro $C^1$ (`chamferMm`) + espessura exata (`thicknessMm`).
  - Rotação rígida própria (`det = +1`) apoiando ambas as metades planas em `Z = 0` sem suportes internos.
  - Auditoria topológica real (`meshAudit.ts`), Binary STL + parser endurecido + empacotador `.ZIP` CRC-32 (`stlCodec.ts`) e economia SIGTAP + curva térmica exotérmica (`economics.ts`).
- **Studio 3D & Storytelling (`ARA-604`):** Interface 2 abas com Corte Transversal em tempo real (Clipping Plane Axial/Coronal/Sagital), animação de prensagem 60 FPS desacoplada, 4 casos sintéticos (incluindo `bifrontal` bilateral), customizador de falha, gráfico de segurança térmica do PMMA e modal de Protocolo PETG/ETO.
- **Paridade CLI Python & Amostras (`ARA-605`):** `engine/cranio_mold_cli.py` atualizado com paridade matemática e JSON v2.0, suíte `pytest` e amostras regeneradas em `samples/`.
